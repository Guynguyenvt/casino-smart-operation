# Casino Smart Operation

Static GitHub Pages build of the Casino Smart Operation live report app.

## Publish with GitHub Pages

1. Create a GitHub repository named `casino-smart-operation`.
2. Upload the files in this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.

The app stores imported reports, mappings, settings, and backups in this browser. The source package contains no casino report workbooks or imported operational data. Folder sync requires Chrome or Edge and the selected folders remain local to each browser/device.
